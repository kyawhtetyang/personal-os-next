# Phase 7 — End-to-End Validation

## Goal

Validate the complete v0.2.0 execution lifecycle using a real capability invocation.

```text
URL
 ↓
Capability
 ↓
Execution
 ↓
Result
 ├── Run
 ├── Artifact
 └── State
```

## Validation commands

```bash
python -m runtime media save "<URL>" --mode audio --audio-format mp3
python -m unittest discover -s tests -v
bash ops/quality_check.sh
git status
```

## Expected

- media artifact created
- run record created
- artifact registry updated
- runtime state updated
- automated tests pass
- generated runtime files ignored by Git

## Release gate

Phase 7 passes only when both automated regression and a real local execution succeed.
