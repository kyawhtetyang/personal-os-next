# Architecture Principles

1. Stable top-level architecture.
2. Capability-first design.
3. What is separate from how.
4. Deterministic execution by default.
5. Verification is required for important execution.
6. Context is selected, not dumped.
7. Models are replaceable.
8. Obsidian is a human interface, not the runtime.
9. Complexity must be earned through real usage.
10. Workflows precede generic orchestration.
